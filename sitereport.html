Introduction

This page is a report about my experience building this portfolio website for CSY1063. I am writing it like a log, going through the term and talking about what I learned, what went wrong, and what I would do differently. I am still new to web development, so there were a lot of mistakes along the way, but I learned a lot from fixing them.

My Development Log

Getting started with HTML

At the start I did not really know the difference between tags like <div> and <section>. My first version of the navigation bar used a <div class="nav"> because that is what I saw in old tutorials. Later I learned that HTML has proper tags for things like navigation, so I changed it to a real <nav> tag. I did the same thing for <header>, <main> and <footer> instead of just using divs for everything.

Building the projects page

For project.html I had to use a different grid layout than the rest of the site. I used CSS Grid instead of the simple layout I used everywhere else. It took me a while to understand how grid-template-columns worked, and my images kept stretching in weird ways until I learned about object-fit.

Making the contact form

The contact page needed a form, but since we are not using a server-side language in this module, I made the form use a mailto link so it opens the user's email app instead. It is not the best way to do it in a real website, but it was the only option we could use for this assignment.

Skills and blog pages

On skills.html I used a table for things like my education and certifications, and a list for my soft skills, because a table made more sense for information that has rows and columns. The blog page was more fun to make because I just had to write about a topic and add pictures that matched what I was talking about.

Making it responsive

Making the site work on mobile was the hardest part for me. At first my media queries were a mess and things overlapped on smaller screens. I had to go back and rewrite a lot of my CSS to make it work properly on both desktop and mobile.

Design Decisions

I chose pink,yellow and white because pink and yellow goes with the old vintage vibes . For the fonts i used Arial, sans-serif because it looks simple . I looked at many random sites and pages for ideas on how to lay out my pages.

Ups and Downs

Learning new codes,layouts,CSS design made it fun

For me doing the CSS was really hard making it responsive was much harder

Next time i'll use animations and many new design in my web page
