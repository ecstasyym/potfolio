Why I Started Learning Web Development

I started learning web development because I wanted to build things that people could actually use. At first, HTML and CSS felt confusing, but the more I practiced, the more it started to make sense. Seeing a plain text file turn into a real webpage with colors, layout, and links felt like magic the first time it worked.

One thing I learned early on is that small mistakes, like a missing closing tag, can break an entire page. So now I always double check my code before saving. Step by step, I am getting more comfortable building full websites like this portfolio.
